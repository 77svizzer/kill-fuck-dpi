# KILL F#CK DPI

> **Полностью автономная, ультрабыстрая C++ утилита обхода DPI / ТСПУ для Windows на базе WinDivert.**
> Архитектура уровня `zapret` (`winws`), но в виде единого автономного C++17 бинарника. **Полная независимость: БЕЗ winws, БЕЗ cygwin и БЕЗ zapret.**
> Обходит всё: **YouTube (4K 60fps без буферизации)**, **Discord (текстовые каналы, CDN медиа и голосовые комнаты 50000–65535)**, **все заблокированные сайты (Instagram, Twitter/X, Rutracker и др.)**.
> **100% стабильность в играх:** Counter-Strike 2, Xplay.gg, FACEIT Anti-Cheat на портах `27000–27100` аппаратно исключены из драйвера WinDivert и идут напрямую через стек ядра NDIS с нулевой задержкой и нулевыми потерями.

## ⚡ Архитектура и передовые техники обхода

1. **RFC 6066 TLS SNI парсер и вычисление midsld:**
   - Нативный C++ парсер разбирает расширения TLS ClientHello (`Server Name Indication`).
   - Для доменов второго уровня автоматически вычисляется точка разделения ровно посередине имени домена (`midsld`), например `googlevideo.com` делится на `googl` и `evideo.com`.
   - ТСПУ сигнатурный анализ ломается, так как регулярные выражения и строковые поисковики не находят имя заблокированного ресурса ни в первом, ни во втором фрагменте.

2. **Техники Fooling: Fake + badsum и autottl:**
   - **`fake_split2` / `fake_disorder`**: перед реальными данными отправляется специально сформированный фейковый TLS ClientHello.
   - **`badsum` (Испорченная контрольная сумма TCP 0xDEAD)**: фейковый пакет помечается флагами `TCPChecksum = 1` и `IPChecksum = 1`. ТСПУ с целью оптимизации ресурсов не проверяет контрольные суммы и запоминает фейковый сеанс, а конечный сервер (Google/Cloudflare/Discord) отбрасывает фейк на уровне сетевого стека ядра.
   - **`autottl`**: фейковый пакет отправляется с заниженным TTL (по умолчанию 6 хопов). Он достигает оборудования ТСПУ провайдера и «умирает» до того, как дойдет до целевого сервера.

3. **Discord Voice UDP (порты 50000–65535):**
   - Перехват и десинхронизация первичных WebRTC/STUN пакетов подключения к голосовым серверам Discord.
   - Отправка STUN Binding Request с фейковым заголовком и кэшированием сессий `(SrcIP:SrcPort -> DstIP:DstPort)`, предотвращая забивание канала повторными пакетами во время разговора.

4. **Многопрофильная маршрутизация по спискам (`lists/`):**
   - Встроенный singleton `HostlistManager` считывает домены из директории `lists/`:
     - `list-google.txt` -> Профиль YouTube (QUIC drop + TLS midsld split2 + badsum)
     - `list-gaming.txt` -> Профиль Discord / Gaming (TLS fake disorder + UDP voice STUN)
     - `list-general.txt` / `list-general-user.txt` -> Профиль General (TLS fake split2)
     - `list-exclude.txt` / `list-exclude-user.txt` -> Прямой пропуск без модификации (DirectBypass)

5. **Аппаратная изоляция игрового трафика (CS2, Xplay, FACEIT):**
   - Порты `27000–27100` аппаратно исключены в фильтре WinDivert:
     ```text
     outbound and !loopback and (
       (tcp and (tcp.DstPort == 80 or tcp.DstPort == 443) and tcp.PayloadLength > 0) or
       (udp and udp.DstPort == 443) or
       (udp and udp.DstPort >= 50000 and udp.DstPort <= 65535 and !(udp.DstPort >= 27000 and udp.DstPort <= 27100))
     )
     ```
   - Пинг не увеличивается ни на 0.1 мс, античиты FACEIT и VAC работают штатно.

6. **Гарантированная безопасность сетевого стека Windows:**
   - Никаких зависаний при перезагрузке ПК: драйвер WinDivert мгновенно и корректно выгружается из ядра при закрытии.
   - Утилита полностью автономна, работает как через удобный GUI (Win32), так и в консольном режиме.

## 🚀 Быстрый запуск

1. Перейдите в папку **`kill-fuck-dpi-main`** (или `projects\kill-fuck-dpi`).
2. Запустите файл **`start.bat`** от имени Администратора.
3. Выберите нужный режим:
   - **`[1]`** — **Запустить обход DPI с графическим интерфейсом и треем Windows**;
   - **`[2]`** — **Запустить в консоли** (для наглядного мониторинга пакетов и статистики в реальном времени);
   - **`[3]`** — **Экстренная очистка и восстановление сети** (полный сброс сетевых драйверов WinDivert);
   - **`[4]`** — Открыть файл настроек `config.ini`;
   - **`[5]`** — Автоматическая проверка доступности YouTube, Discord, CS2/FACEIT/Xplay.

## ⚙️ Конфигурация (`config.ini`)

```ini
[General]
# Стратегия десинхронизации: fake_split2, fake_disorder, split2, disorder
strategy = fake_split2

# Позиция разделения TLS ClientHello: midsld (по центру домена), sni, или число байт (напр. 2)
split_position = midsld

# Техники обмана ТСПУ (fooling): badsum (испорченная чексумма), autottl (низкий TTL)
fooling = badsum

# Значение TTL для фейковых пакетов при autottl
fake_ttl = 6

# Сброс исходящего QUIC на UDP 443 для моментального 4K в YouTube
drop_quic = true

# Обход блокировок голосовых комнат Discord UDP 50000-65535
discord_voice_fake = true

# Использовать списки доменов из папки lists/
use_hostlists = true

# Целевые TCP порты для веб-трафика
target_ports = 80, 443
```
