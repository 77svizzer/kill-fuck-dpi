# KILL F#CK DPI

> **Полностью автономная, легковесная локальная C++ утилита обхода DPI / ТСПУ для Windows на базе WinDivert.**
> Разработана с нуля на чистом C++17. **Полная независимость: БЕЗ winws, БЕЗ cygwin и БЕЗ zapret.**
> Обходит всё: **YouTube (4K 60fps)**, **Discord (чат, медиа и голосовые каналы)**, **все заблокированные сайты (Instagram, Twitter/X, Rutracker и др.)**.
> **100% совместимость с играми:** Counter-Strike 2, Xplay.gg, FACEIT Anti-Cheat и европейские сервера работают напрямую через сетевой стек с нулевой задержкой и нулевой потерей пакетов.

## ⚡ Архитектура и принцип работы (Native C++)

1. **Полная независимость (Zero-Third-Party Dependencies):**
   - Утилита собрана нативном компилятором MSVC под x64.
   - Использует исключительно драйвер перехвата ядра Windows `WinDivert.dll` и `WinDivert64.sys`.
   - Никаких эмуляторов POSIX, cygwin1.dll, winws или внешних bat-обвязок.

2. **Инверсия сегментов TLS (Disorder / Reverse TCP Split):**
   - Утилита анализирует только исходящие TCP-пакеты с полезной нагрузкой на портах 80 и 443.
   - При обнаружении TLS ClientHello (`ContentType == 0x16`, `Version >= 0x0301`, `HandshakeType == 0x01`) полезная нагрузка прозрачно делится на два TCP-сегмента:
     - **Сегмент 1:** первые $N$ байт (по умолчанию 2 байта);
     - **Сегмент 2:** тело ClientHello с SNI (Server Name Indication).
   - **Сегмент 2 отправляется ПЕРВЫМ, а Сегмент 1 — ВТОРЫМ (Disorder).**
   - ТСПУ ожидает заголовок TLS в начале потока и не может сопоставить имя заблокированного домена. В то же время удалённый сервер (Google, Cloudflare, Discord) восстанавливает корректный порядок по TCP Sequence Numbers (`SeqNum`) без использования фейковых пакетов, которые часто вызывают сброс соединения со стороны Cloudflare (благодаря чему **xplay.gg** и другие защищённые Cloudflare сервисы открываются моментально).

3. **Сброс QUIC на порту UDP 443 (YouTube 4K без буферизации):**
   - Пакеты QUIC на порт UDP 443 сбрасываются драйвером.
   - Браузеры (Chrome, Edge, Firefox) моментально (за 1 мс) переключаются на высокоскоростной протокол TCP HTTP/2 с TLS-десинхронизацией.
   - Видеопотоки YouTube в 1080p, 2K и 4K 60fps воспроизводятся без задержек и подвисаний.

4. **Аппаратная изоляция игрового трафика (Xplay, CS2, FACEIT):**
   - Фильтр ядра WinDivert настроен строго на:
     ```text
     outbound and ((tcp and (tcp.DstPort == 80 or tcp.DstPort == 443) and tcp.PayloadLength > 0) or (udp and udp.DstPort == 443))
     ```
   - **Любые игровые UDP-порты (Counter-Strike 2, серверы сообщества Xplay.gg на портах 27015–27050+, FACEIT EU, Discord Voice 50000–65535) ВООБЩЕ НЕ ПЕРЕХВАТЫВАЮТСЯ**.
   - Пакеты идут по прямому тракту ядра Windows в сетевую карту. Пинг не увеличивается ни на 1 мс, джиттер 0%, потери 0%.

5. **Встроенное управление службой Windows:**
   - Бинарник `dpi_bypass.exe` содержит нативный обработчик `StartServiceCtrlDispatcher`.
   - При установке через меню регистрируется системная служба `KillFuckDPI` с автозапуском (`start= auto`).
   - Работает в тихом фоне: **без консоли, без вылетов, без спама цифр**.

## 🚀 Быстрый старт (За 5 секунд)

1. Откройте папку **`kill-fuck-dpi-main`** на Рабочем столе (или в `projects`).
2. Запустите файл **`start.bat`** (подтвердите UAC-запрос прав Администратора).
3. В меню выберите:
   - **`[1]`** — **Установить и запустить службу Windows** (работает ВСЕГДА в фоне при включении ПК);
   - **`[2]`** — **Запустить в консоли** (для наглядной проверки статуса с компактным счётчиком);
   - **`[3]`** — **Остановить и удалить службу**;
   - **`[4]`** — Открыть файл настроек `config.ini`;
   - **`[5]`** — Автоматическая проверка доступности YouTube, Discord, CS2/FACEIT/Xplay.

## ⚙️ Конфигурация (`config.ini`)

```ini
[General]
# Позиция разделения TLS ClientHello (в байтах)
split_position = 2

# Инверсия порядка TCP сегментов (Disorder / Reverse split)
disorder = true

# Сброс исходящего QUIC на UDP 443 для мгновенного 4K в YouTube
drop_quic = true

# Целевые TCP порты
target_ports = 80, 443
```
