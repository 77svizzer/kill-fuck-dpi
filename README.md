# KILL F#CK DPI

> **Легковесная локальная C++ утилита обхода систем глубокого анализа пакетов (DPI / ТСПУ) для Windows на базе WinDivert.**
> Работает полностью автономно на вашем компьютере: не требует внешних VPS серверов, Shadowsocks, V2Ray или прокси. 100% совместима с соревновательными играми, сетевыми шутерами и античитами (FACEIT Anti-Cheat, Counter-Strike 2, Valorant).

---

## 🎯 Ключевые возможности

1. **Полная локальность (Zero-Proxy):**
   - Никаких внешних серверов, аренды VPS, туннелей или задержек пинга.
   - Манипуляция сетевыми пакетами происходит прямо на вашем ПК через платформу фильтрации Windows (WFP / WinDivert).

2. **Аппаратная изоляция игрового UDP-трафика:**
   - Фильтр ядра WinDivert настроен строго на исходящий TCP-трафик:
     ```text
     outbound and tcp and (tcp.DstPort == 80 or tcp.DstPort == 443) and tcp.PayloadLength > 0
     ```
   - **Любой UDP трафик аппаратно игнорируется драйвером ядра**. Игровые пакеты CS2 (порты 27015–27050, кастомные серверы FACEIT EU), драйвер ядра FACEIT Anti-Cheat и голосовые каналы Discord передаются операционной системой напрямую без малейших задержек или интерференций.

3. **Фрагментация TLS ClientHello (TCP-level Out-of-Band Split):**
   - Утилита инспектирует только TCP-пакеты с полезной нагрузкой.
   - При обнаружении TLS рукопожатия (`ContentType == 0x16`, `Version == 0x03`, `HandshakeType == 0x01`) полезная нагрузка прозрачно делится на два отдельных TCP-сегмента (по умолчанию на 2 байта + остаток, либо на 1 байт в агрессивном режиме).
   - Корректируются заголовки IP (`Length`, `Id`), TCP (`SeqNum`), и драйвер `WinDivertHelperCalcChecksums` аппаратно пересчитывает контрольные суммы.
   - Системы ТСПУ/DPI не могут собрать SNI (Server Name Indication) из разрозненных сегментов в потоке без дорогостоящей полной сборки сессии, и соединение беспрепятственно устанавливается.

4. **Мгновенный Passthrough для остального трафика:**
   - Все пакеты, не являющиеся TLS ClientHello (ACK, FIN, HTTP GET/POST, обычные данные), передаются немедленно без задержек.

5. **Безопасное завершение и очистка драйвера:**
   - При нажатии `Ctrl + C` или выборе пункта в `start.bat` дескриптор WinDivert немедленно закрывается, а драйвер `WinDivert64.sys` безопасно выгружается из ядра Windows.

## 🚀 Быстрый старт

### Требования
- 64-битная Windows 10 или Windows 11.
- Права Администратора (для загрузки драйвера WinDivert).

### Запуск через интерактивное меню
1. Запустите файл `start.bat`. Если он открыт без прав администратора, скрипт автоматически запросит подтверждение UAC через PowerShell.
2. В появившемся меню выберите нужный пункт:
   - `[1]` — **Стандартный режим (2 байта)**: Безопасный, идеален для повседневного использования, стриминга и серфинга. Полная совместимость с FACEIT.
   - `[2]` — **Агрессивный режим (1 байт)**: Разрезает ClientHello на 1 байт. Эффективен против жестких блокировок и глубоких эвристик ТСПУ.
   - `[3]` — Открыть `config.ini` в Блокноте для быстрой настройки.
   - `[4]` — Остановить все процессы и очистить службы.
   - `[5]` — Выход.

## ⚙️ Конфигурация (`config.ini`)

```ini
[General]
# Позиция разделения TLS ClientHello (в байтах).
# 2: Стандартный безопасный режим.
# 1: Агрессивный режим против жестких замедлений.
split_position = 2

# Целевые TCP порты для перехвата (через запятую).
target_ports = 80, 443

# Изоляция игрового UDP-трафика (CS2, FACEIT, Discord Voice).
isolate_game_udp = true
```

## 🛠️ Сборка из исходников

### Способ 1: Автоматическая сборка через `build.bat` (MSVC x64)
Просто запустите:
```cmd
build.bat
```
Скрипт автоматически найдет окружение Visual Studio (2022 / Build Tools) и скомпилирует оптимизированный бинарник `dpi_bypass.exe`.

### Способ 2: Сборка через CMake
```cmd
mkdir build
cd build
cmake ..
cmake --build . --config Release
```
CMake автоматически скопирует `WinDivert.dll`, `WinDivert64.sys` и `config.ini` в папку с собранным файлом `Release\dpi_bypass.exe`.

### Способ 3: Ручная компиляция через `cl.exe` (Developer Command Prompt)
```cmd
cl.exe /nologo /EHsc /O2 /utf-8 /std:c++17 /Iinclude src\main.cpp /link /LIBPATH:lib WinDivert.lib ws2_32.lib advapi32.lib /OUT:dpi_bypass.exe
```

### Способ 4: Компиляция через MinGW-w64 (`g++`)
```bash
g++ -O2 -std=c++17 -Iinclude src/main.cpp -Llib -lWinDivert -lws2_32 -ladvapi32 -o dpi_bypass.exe
```

## 🛡️ Безопасность и античиты (CS2 / FACEIT)

Многие утилиты обхода блокировок вызывают проблемы в соревновательных играх, перехватывая все сетевые пакеты подряд или пропуская UDP через локальные прокси-ноды, что приводит к:
- скачкам пинга и потере пакетов (Loss / Choke);
- блокировкам со стороны античитов, таких как **FACEIT Anti-Cheat** или **Easy Anti-Cheat**;
- невозможности подключения к серверам игровых сообществ.

**Почему KILL F#CK DPI безопасен:**
1. **Фильтрация на уровне ядра WFP:** Правило фильтрации WinDivert задействует выражение `outbound and tcp`. Драйвер сетевого уровня ядра вообще не трогает UDP-пакеты. Они даже не копируются в пространство пользователя.
2. **Нулевой лаг:** Игровые пакеты идут по стандартному быстрому сетевому пути ядра Windows напрямую в сетевую карту.
3. **Отсутствие хуков на процессы:** Утилита не внедряет DLL в процессы игр (`no code injection`) и не перехватывает системные вызовы сокетов (Winsock LSP / WFP callout хуки процессов не используются).
